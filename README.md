## 🚀 Como hospedar

### Opção 1 — GitHub Pages (Grátis)
1. Vai a [github.com](https://github.com) → **New repository**
2. Nome: `tufao-site` (ou o que quiseres)
3. Visibilidade: **Public**
4. Faz upload do `index.html`
5. Vai a **Settings → Pages → Source → main branch**
6. O teu site fica em: `https://SEU-USER.github.io/tufao-site`

### Opção 2 — Netlify Drop (Grátis, mais fácil)
1. Vai a [netlify.com/drop](https://app.netlify.com/drop)
2. Arrasta a pasta **"tufão site"** para lá
3. Pronto — URL gerada automaticamente em segundos

### Opção 3 — Vercel (Grátis)
1. Vai a [vercel.com](https://vercel.com) → **Add New Project**
2. Importa o repositório do GitHub
3. Deploy automático
